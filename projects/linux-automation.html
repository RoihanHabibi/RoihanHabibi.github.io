PROJECT 03 — AUTOMATION

Linux Server Automation

Linux server automation environment designed to simplify repetitive server administration tasks through centralized Ansible automation.

Linux Ansible SSH Playbook Inventory

01 — OVERVIEW

Project Overview

This project focuses on automating Linux server administration using Ansible. A centralized control node is used to manage Linux servers through SSH-based communication and reusable playbooks.

02 — PROBLEM

Problem

Repetitive server administration tasks can require significant manual effort when performed individually across multiple Linux systems.

The goal of this project was to centralize server configuration and automate repetitive operational tasks using Ansible.
