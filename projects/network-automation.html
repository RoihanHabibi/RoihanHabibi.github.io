02 — NETWORK AUTOMATION

MikroTik & OLT Network Automation

Network automation project focused on streamlining network provisioning and device configuration through a centralized web-based workflow.

01 — OVERVIEW

Project Overview

This project focuses on automating network provisioning tasks involving MikroTik and Optical Line Terminal (OLT) infrastructure.

The system is designed around a centralized workflow where network operations can be initiated through a web interface and processed by a backend automation service.

02 — PROBLEM

Problem

Network provisioning can involve repetitive configuration steps and different command structures depending on the network device and vendor.

Performing these operations manually can make the provisioning process more time-consuming and increase the possibility of configuration errors.

The project therefore focuses on creating a more centralized and consistent automation workflow.
